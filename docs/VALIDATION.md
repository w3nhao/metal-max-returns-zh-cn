# 测试范围

补丁以 4 MiB 无复制头日版为唯一输入，经过两种独立 BPS 实现回填，得到相同输出。随附 Python 安装脚本同时检查文件大小、SHA-256 和 BPS 校验值。

## 已检查

- 普通对白、翻页、确认关闭、菜单打开与返回。
- 保存后退出、冷启动读取，以及代表画面资源的回归。
- BS 机功能文字、道具说明、商店详情关闭与重开。
- 车辆改造、按摩、仓库寄存与正常服务返回等有限功能场景。
- 非零悬赏结算：数量 2、奖金 12G，确认后现金增加 12G，计数清零并回到服务菜单。
- 招募拒绝语“去!去!”在辅助显示场景中的完整显示与正常关闭。

其中部分功能采用独立测试入口；这些证据证明对应显示或返回机制，不代表最终版本的完整原事件路线已覆盖。补丁输出身份见 [release.json](../patch/release.json)。

## 尚待验证
