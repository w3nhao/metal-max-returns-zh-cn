# 重装机兵 Returns 简体中文修订

基于 0.96 简体汉化版，修订对白、装备与物品名称，补充功能提示，并修复部分中文显示。适用于 SFC 日版《Metal Max Returns》。当前版本：**0.1.0 公开测试版**。

[**下载补丁包**](https://github.com/w3nhao/metal-max-returns-zh-cn/releases/tag/v0.1.0)

补丁包含原 0.96 汉化和本次修订，从未修改的日版一次安装，无需先打旧汉化补丁。

## 安装

1. 下载并解压补丁包，准备自己的未修改日版游戏文件。
2. 用支持 BPS 的工具选择 `patch/METAL_MAX_RETURNS_JP_TO_ZH.bps`、日版文件和新的输出文件。
3. 用 SFC 模拟器或兼容设备打开生成的文件。

日版须为 **4 MiB（4,194,304 字节）、不带 512 字节复制头**。输入 SHA-256：

```text
6a68e1806d8d72accb4a5218330210e178880216863c1c38b8865032c5c28724
```

也可使用 Python 3，无需安装额外依赖。在解压后的补丁目录运行：

```text
python patch/apply_patch.py "Metal Max Returns (Japan).sfc" "Metal Max Returns (Chinese).sfc"
```

如果只下载 `patch` 目录，在该目录运行时将脚本路径改为 `apply_patch.py`。输入也可为包含唯一 `.sfc` 或 `.smc` 文件的 ZIP。脚本检查输入、补丁和输出身份，拒绝覆盖已有输出。原 0.96 中文版不适合作为补丁输入。

## 修订内容

- 整理对白、服务消息、装备与物品名称，修正误译、缺字和表达不清。
- 补充 BS 机功能标题，修订商店与道具说明、车辆容量等提示。
- 添加车库“寄存”招牌，修复部分窗口文字显示与末尾控制标记。
- 保留符合场景的品牌、缩写和外文标识，不以全部改成中文为目标。

## 验证范围与已知限制

已检查普通对白、菜单往返、代表道具与商店画面，以及保存后冷启动读取。若干功能通过有限测试入口检查，不能等同于全剧情覆盖。

以下场景尚未全部验证：特殊决斗的额外确认与选人接续，卖空车载物品与满栏取回，悬赏过期目标分支。新增招募拒绝语“去!去!”通过了显示与关窗检查，原招募事件的自然触发仍待验证。

当前继承原版小字体，大字体方案后置。没有完成全流程通关或逐句人工终审；存档跨版本兼容性也未全面检查。详细范围见[测试说明](docs/VALIDATION.md)。
