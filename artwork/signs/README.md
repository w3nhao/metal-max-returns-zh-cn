# 寄存招牌文字布局

[storage-sign.png](storage-sign.png)是“寄存”两字的独立文字预览，采用32×8像素布局并放大8倍，包含正文、左阴影和预览底色。它由字体字形生成，不是游戏截图，也不含游戏原背景或整块图形资源。布局规则见[storage-sign-layout.json](storage-sign-layout.json)。

字形采用 TakWolf 的 [Fusion Pixel Font](https://github.com/TakWolf/fusion-pixel-font)，8px Mono zh_Hans，版本2026.09.25。字体并非本项目原创；本项目完成文字布局、纵向移位、阴影及游戏格式整合。相关版权及授权见[licenses](licenses/)，保留了 Fusion Pixel 声明与上游 BoutiqueBitmap7x7/MisakiGothic、Galmuri、Miseki Bitmap 授权文本。
